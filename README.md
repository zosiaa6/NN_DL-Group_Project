## Project Description
Our project is concerned with the problem of classifying news articles based on their titles and abstracts
into one of the following categories: Business, Sports, World, and Sci/Tech. As our baseline, we will use
the Support Vector Machine (SVM) architecture. We chose SVM because they can handle sparse, high-
dimensional text data in classification tasks. Then, we will train a Long Short-Term Memory (LSTM)
neural network as our second model. Lastly, we will fine-tune a BERT transformer on our text data. We
chose these architectures because their fundamentally different architectures allow for a fair comparison
to see their different capabilities.

We will compare the SVM, LSTM, and DistilBERT using accuracy, Macro-F1, and loss results from
evaluating on the test set and by constructing confusion matrices

Our research question is: **How do traditional machine learning approaches and neural network architectures, specifically SVM, LSTM, and DistilBERT, compare in their performance on the AG News classification task?**

## Running the code

Set up a virtual environment

```bash
    uv init --python3.12
```

Install dependencies

```bash
    uv sync
```

Activate the virtual environment

```bash
    source .venv/bin/activate
```
